# PocketBeagle 2 3D model

`pocketbeagle2_v03_21_EVT.stp` is BeagleBoard.org's own model of the PocketBeagle 2 (EVT revision v03_21),
unmodified, from <https://openbeagle.org/pocketbeagle/pocketbeagle-2> (`design/old/`).

© BeagleBoard.org Foundation — licensed under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/).
The web copy `site/assets/pocketbeagle2.glb` is a format conversion of it (KiCad GLB export + gltfpack compression, with
uncoloured pads/soldermask recoloured at load time) and is shared under the same licence.
